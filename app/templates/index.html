Data Dictionary Comparison Tool

This application is a prototype automation platform for regression testing Data Dictionary releases. Hopefully to be implemented within the QA function at Covéa Insurance.

A Data Dictionary change is an update to the content of insurance rating data and underwriting rules, which may affect how quotes and premiums are calculated across different software houses.

Overview:

  • Select scenarios on the Comparison page
  • Run comparison to populate the results table
  • Review outcomes if any differences are found or successfull comparison
  • Also view any past runs as an audit testing trail

Use the navigation bar to access required areas and if applicable the admin area.
